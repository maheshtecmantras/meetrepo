**Test Case 1: Booking Confirmation Notification Verification**

*   **Title:** Verify Booking Confirmation Notification Displays Correctly and On Time
*   **Description:** This test case verifies that the user receives a booking confirmation notification immediately after a booking is successfully created, and that the notification contains the correct information.
*   **Steps:**

    1.  **Pre-condition:** User is logged into the system with appropriate permissions to make bookings. Notifications are enabled for the user.
    2.  **Navigate:** Go to the "Create Booking" section of the application.
    3.  **Input Data:** Enter all required booking details (e.g., date, time, guest name, table number, special requests). Ensure valid data is entered.
    4.  **Submit Booking:** Click the "Confirm Booking" or equivalent button to submit the booking request.
    5.  **Monitor Notifications:** Immediately after clicking "Confirm Booking", observe the notification area of the application (or the user's designated notification channel, e.g., email, in-app notifications).
    6.  **Record Notification Details:** If a notification appears, record the following:
        *   The title of the notification.
        *   The body/content of the notification.
        *   The timestamp of when the notification appeared.
    7.  **Verify Booking Details in Notification:** Compare the booking details in the notification with the data entered in step 3.
    8.  **Navigate to booking details:** Click on the notification (if applicable and if it navigates to the booking details page). Verify that the details on the booking details page match with the notification.

*   **Expected Result:**

    1.  A booking confirmation notification appears within 5 seconds (This time can be adjusted based on performance SLA).
    2.  The notification title is clear and relevant (e.g., "Booking Confirmed," "Your Reservation is Confirmed").
    3.  The notification body contains accurate and complete booking details, including:
        *   Guest Name
        *   Date and Time of Booking
        *   Table Number (if applicable)
        *   Any special requests added.
        *   Booking reference/ID.
    4.  The timestamp on the notification is accurate and reflects the time the booking was confirmed.
    5.  Clicking on the notification should redirect the user to the booking details page, displaying all the information from the notification.
    6.   The data on the booking details page matches the information provided in the notification.

*   **Priority:** High

**Test Case 2: Verify Successfully Deleted Guest Notification**

*   **Title:** Verify "Successfully Deleted Guest" Notification Display and Content
*   **Description:**  This test case verifies that when a guest is successfully deleted from a guest list, a confirmation notification is displayed to the user who initiated the deletion, and that the notification is informative and accurate.
*   **Steps:**

    1.  **Pre-condition:** User is logged into the system with permissions to manage guest lists and delete guests. Guest list exists with at least one guest. Notifications are enabled for the user.
    2.  **Navigate:** Navigate to the "Guest List Management" section of the application.
    3.  **Select Guest List:** Select a guest list containing at least one guest.
    4.  **Select Guest to Delete:** Identify a guest in the list and select the "Delete" action (e.g., click a delete icon or button).
    5.  **Confirm Deletion:** Confirm the deletion in any confirmation dialog or prompt that appears.
    6.  **Monitor Notifications:** Immediately after confirming the deletion, observe the notification area of the application (or the user's designated notification channel).
    7.  **Record Notification Details:** If a notification appears, record the following:
        *   The title of the notification.
        *   The body/content of the notification.
        *   The timestamp of when the notification appeared.
    8.  **Verify Guest Absence:** Refresh the guest list and verify that the deleted guest is no longer present in the list.
    9.  **Verify Deleted Guest Details in Notification:** Confirm the notification contains the name of the deleted guest.

*   **Expected Result:**

    1.  A "Successfully Deleted Guest" notification appears within 3 seconds.
    2.  The notification title is clear and indicates success (e.g., "Guest Deleted", "Guest Removed").
    3.  The notification body confirms the action and includes the name of the deleted guest (e.g., "Guest 'John Doe' has been successfully removed from the guest list.")
    4.  The timestamp on the notification is accurate.
    5.  The deleted guest is no longer visible in the guest list after refreshing the page.

*   **Priority:** High
