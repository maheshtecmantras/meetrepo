# Test Cases for T2.2.2 - Contact Information Clubbing

Okay, here are two detailed test cases covering the "Contact Information Clubbing" task. They focus on slightly different aspects of adding Venue Manager contact details, ensuring a good level of coverage.

**Test Case 1: Adding a New Venue Manager Contact with Valid Information**

*   **Title:** Add New Venue Manager Contact - Valid Data

*   **Description:** This test case verifies the successful creation of a new Venue Manager contact with all required fields populated with valid data, including verifying proper saving and display.

*   **Steps:**

    1.  Navigate to the "Venue Manager Contact" section of the application (e.g., through the admin panel or a designated contact management page).  Assume user has the necessary permissions.
    2.  Click the "Add New Contact" or similar button/link.
    3.  On the "Add Venue Manager Contact" form, enter valid data into the following fields:
        *   **First Name:** "John"
        *   **Last Name:** "Doe"
        *   **Email Address:** "john.doe@example.com" (Check this is valid format)
        *   **Phone Number:** "+15551234567" (Check this is valid format and length)
        *   **Venue Assignment:** Select a valid Venue from the dropdown list. (e.g., "Stadium Arena")
        *   **Title/Position:** "Event Coordinator"
        *   **Notes:** "Primary contact for event bookings."
    4.  Click the "Save" or "Submit" button.
    5.  Verify the system displays a success message (e.g., "Contact successfully created.").
    6.  Navigate to the "Venue Manager Contact" list or view the newly created contact detail page.
    7.  Verify the newly created contact is present in the list and the details (First Name, Last Name, Email Address, Phone Number, Venue Assignment, Title/Position, Notes) displayed match exactly the data entered in Step 3.
    8. Select the venue that was assigned to the contact from the venue list.
    9. Verify the newly created contact is displayed in the list of contact associated with that venue.

*   **Expected Result:**

    *   A success message is displayed upon saving.
    *   The new Venue Manager contact is successfully created and visible in the contact list or detail view.
    *   All entered data (First Name, Last Name, Email Address, Phone Number, Venue Assignment, Title/Position, Notes) is correctly saved and displayed.
    *   The new contact is displayed in the contact list associated with the assigned venue.

*   **Priority:** High
**Test Case 2: Adding a New Venue Manager Contact with Invalid Information**

*   **Title:** Add New Venue Manager Contact - Invalid Data

*   **Description:** This test case verifies that the application handles invalid data entry correctly when creating a new Venue Manager contact, including proper validation and error messaging.

*   **Steps:**

    1.  Navigate to the "Venue Manager Contact" section of the application.
    2.  Click the "Add New Contact" or similar button/link.
    3.  On the "Add Venue Manager Contact" form, enter the following invalid data:
        *   **First Name:** "" (Empty)
        *   **Last Name:** "" (Empty)
        *   **Email Address:** "invalid_email" (Invalid format)
        *   **Phone Number:** "123" (Too short)
        *   **Venue Assignment:** Leave the Venue Assignment field blank/unselected.
        *   **Title/Position:** A string with more than the allowed number of characters.
        *   **Notes:** A string with more than the allowed number of characters.
    4.  Click the "Save" or "Submit" button.
    5. Verify the system displays error messages for the invalid fields
        *   "First Name is required"
        *   "Last Name is required"
        *   "Email Address is invalid"
        *   "Phone Number is invalid"
        *   "Venue Assignment is required"
        *   "Title exceeds character limit"
        *   "Notes exceed character limit"
    6.  Verify that the contact record is *not* created and that the user remains on the "Add Venue Manager Contact" form.
    7. Correct the information in the fields to valid data and re-submit the form.

*   **Expected Result:**

    *   The system displays appropriate error messages for each invalid field. The error messages should be clear and helpful to the user.
    *   No Venue Manager contact is created with the invalid data.
    *   The user remains on the "Add Venue Manager Contact" form, allowing them to correct the errors.
    *   The system allows the user to resubmit after entering valid data.

*   **Priority:** High
