# Test Cases for T2.2.1 - Basic Details Clubbing

Okay, here are two detailed test cases based on the provided "Basic Details Clubbing" task, written from the perspective of a senior QA engineer.

**Test Case 1: Valid Data Entry for Club Basic Details**

*   **Title:** Verify Successful Creation of Club with Valid Basic Details

*   **Description:**  This test case validates the ability to successfully create a new club profile by entering valid data into all required and optional fields for Name, Address, Phone Number, Logo, and Venue Type (bar, club, lounge).  The focus is on positive testing, ensuring the system accepts well-formed data.

*   **Steps:**

    1.  **Pre-condition:** User is logged in and has the necessary permissions to create a new club profile.  User is navigated to the "Create New Club" or "Add Club" page.
    2.  **Step 1:** Enter a valid Club Name (e.g., "The Galaxy Lounge") into the 'Club Name' field.
    3.  **Step 2:** Enter a valid Address (e.g., "123 Main Street, Anytown, CA 91234") into the 'Address' field.  Include street address, city, state, and zip code.
    4.  **Step 3:** Enter a valid 10-digit Phone Number (e.g., "555-123-4567") into the 'Phone Number' field.
    5.  **Step 4:** Upload a valid Logo image file (e.g., a .jpg or .png file under 5MB) using the 'Upload Logo' functionality.  Verify the file uploads successfully.
    6.  **Step 5:** Select a Venue Type (e.g., "Club") from the available options (bar, club, lounge) using the dropdown or radio buttons.
    7.  **Step 6:** Review all entered data to ensure accuracy.
    8.  **Step 7:** Click the "Save" or "Create Club" button.
    9.  **Step 8:** Verify the Club Profile is created successfully.

*   **Expected Result:**

    1.  The system accepts the entered data without any error messages.
    2.  A success message is displayed confirming the club profile creation (e.g., "Club created successfully").
    3.  The user is redirected to the newly created club's profile page.
    4.  On the club profile page, the entered Name, Address, Phone Number, Logo, and Venue Type are displayed correctly.
    5.  The uploaded logo is correctly displayed within the profile page.
    6.  The database should reflect the correctly entered Name, Address, Phone Number and Venue Type.

*   **Priority:** High

**Test Case 2: Invalid Data Entry for Club Basic Details - Phone Number Validation**

*   **Title:** Verify Error Handling for Invalid Phone Number Format

*   **Description:** This test case focuses on negative testing. It aims to verify that the system correctly handles and rejects invalid phone number formats entered during club profile creation. It checks for appropriate error messages and prevents the creation of a club profile with an invalid phone number.

*   **Steps:**

    1.  **Pre-condition:** User is logged in and has the necessary permissions to create a new club profile. User is navigated to the "Create New Club" or "Add Club" page.
    2.  **Step 1:** Enter a valid Club Name (e.g., "The Blue Moon Lounge") into the 'Club Name' field.
    3.  **Step 2:** Enter a valid Address (e.g., "456 Oak Avenue, Anytown, CA 91234") into the 'Address' field.
    4.  **Step 3:** Enter an *invalid* Phone Number (e.g., "123", "abcdefghij", "555-123-456", "555123456789") into the 'Phone Number' field.  Test a variety of invalid formats (too short, too long, containing letters, special characters, missing area code, etc.). Test with the number being blank.
    5.  **Step 4:** Upload a valid Logo image file (e.g., a .jpg or .png file under 5MB) using the 'Upload Logo' functionality.
    6.  **Step 5:** Select a Venue Type (e.g., "Lounge") from the available options (bar, club, lounge).
    7.  **Step 6:** Click the "Save" or "Create Club" button.

*   **Expected Result:**

    1.  The system *does not* create the club profile.
    2.  An appropriate error message is displayed near the 'Phone Number' field, clearly indicating the reason for the error (e.g., "Invalid phone number format. Please enter a 10-digit phone number", "Phone number must contain only digits.", "Phone number cannot be blank.").  The error message should be user-friendly and informative.
    3.  The other fields should retain the data entered in them. This helps with usability.
    4.  The error message should be displayed prominently, preventing the user from accidentally overlooking it.
    5.  The database should not contain any new entries for the club profile.

*   **Priority:** High
