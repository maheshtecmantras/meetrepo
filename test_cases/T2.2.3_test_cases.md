**Test Case 1: Commission Structure Addition - Valid Input**

*   **Title:** Verify Successful Commission Structure Addition with Valid Input.
*   **Description:** This test case verifies that a commission structure can be successfully added to a business agreement using valid input parameters.
*   **Steps:**
    1.  Navigate to the Business Agreement Details page.
    2.  Locate and click the "Add Commission Structure" button/link.
    3.  Enter valid data into all required fields for the commission structure, including:
        *   Commission Type (e.g., Percentage, Fixed Amount)
        *   Commission Value (e.g., 5, 100)
        *   Effective Date (e.g., 2024-01-01)
        *   Applicable To (e.g., All Products, Specific Category)
        *   Any other relevant fields as defined by the application.
    4.  Click the "Save" or "Submit" button.
    5.  Verify that a success message is displayed to the user (e.g., "Commission structure added successfully").
    6.  Verify that the newly added commission structure is displayed correctly in the Business Agreement Details page with all the entered values.

*   **Expected Result:**
    *   The commission structure should be successfully added to the business agreement.
    *   A success message should be displayed to the user.
    *   The newly added commission structure should be displayed correctly in the UI with all the entered values.
    *   The data should be correctly stored in the database and retrievable.
*   **Priority:** High

**Test Case 2: Discount Rate Addition with Boundary Value Analysis**

*   **Title:** Verify Discount Rate Addition using Boundary Value Analysis for Rate Field.
*   **Description:**  This test case verifies that discount rates are handled correctly at the boundaries of the allowed range for the discount rate percentage. Boundary Value Analysis (BVA) is used to test the input of the Discount Rate Percentage field. Assuming the Discount Rate Percentage can be between 0 and 100 (inclusive).
*   **Steps:**
    1.  Navigate to the Business Agreement Details page.
    2.  Locate and click the "Add Discount Rate" button/link.
    3.  Enter valid data into all required fields except the "Discount Rate Percentage".
    4.  For the "Discount Rate Percentage" field, perform the following tests, one at a time, clicking "Save" or "Submit" after each:
        *   a. Enter `-1` (Value Below the Minimum)
        *   b. Enter `0` (Minimum Valid Value)
        *   c. Enter `1` (Value Slightly Above Minimum)
        *   d. Enter `99` (Value Slightly Below Maximum)
        *   e. Enter `100` (Maximum Valid Value)
        *   f. Enter `101` (Value Above the Maximum)
    5.  Record the system's behavior (error messages, acceptance, calculations).

*   **Expected Result:**
    *   For inputs `-1` and `101`, an appropriate error message should be displayed, informing the user that the discount rate must be within the range of 0 to 100. The system should *not* save the invalid data.
    *   For inputs `0`, `1`, `99` and `100`, the discount rate should be successfully added to the business agreement.
    *   A success message should be displayed (if applicable).
    *   The newly added discount rate should be displayed correctly in the UI.
    *   The discount rate calculation should be verified for rates of 0, 1, 99 and 100 to confirm correct function.
*   **Priority:** High
