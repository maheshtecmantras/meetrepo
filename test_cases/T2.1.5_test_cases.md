**Test Case 1: Data Input Validation - Restaurant Venue Profile Table**

*   **Title:** Validate Data Entry for Restaurant Venue Profile Table Fields

*   **Description:** This test case verifies the correct functionality of the data input fields for a Restaurant venue profile in the admin panel. It focuses on validation, data type restrictions, and ensuring data integrity during creation and modification.

*   **Steps:**

    1.  **Navigate:** Log into the admin panel using valid credentials.
    2.  **Access Venue Profile:** Navigate to the "Venue Management" or "Venues" section (Exact label depends on the system).
    3.  **Create New Venue:** Click on the "Add Venue" or "Create Venue" button.
    4.  **Select Venue Type:** Select "Restaurant" as the venue type.
    5.  **Input Valid Data:** Fill in all the required fields in the Restaurant Venue Profile Table with valid data conforming to the expected data type and format (e.g., Name: "The Italian Place", Logo: upload a valid image file, Type: "Casual Dining", Commission: "10", Cuisine: "Italian", Indoors: "Yes", Outdoors: "Yes", Bar: "Yes", Special Events: "Yes", Service Time: "Lunch/Dinner", Min Party Size: "2", Max Party Size: "100", Price Range/Person: "$20-$40", Discount Details: "Happy Hour 5-7pm", Description/Caption: "Authentic Italian cuisine in a cozy atmosphere.").
    6.  **Save Venue:** Click the "Save" or "Create" button.
    7.  **Verify Data:** Navigate back to the newly created venue profile and verify that all the entered data is displayed correctly.
    8.  **Input Invalid Data - Logo:** Attempt to upload a file that is not an image (e.g., a .txt file, a very large file exceeding the permitted size). Observe the system's response.
    9.  **Input Invalid Data - Commission:** Enter a non-numeric value (e.g., "ten percent") into the "Commission" field. Observe the system's response.
    10. **Input Invalid Data - Min/Max Party Size:** Enter non-numeric or negative values, or Max party size less than min party size into "Min/Max Party Size" fields. Observe the system's response.
    11. **Input Invalid Data - Price Range:** Enter invalid price range data (e.g. text, special characters, or an invalid format such as "$50 - $20"). Observe the system's response.
    12. **Clear and repeat steps 5-7 with data that is at the character limit or near it (both low and high).**

*   **Expected Result:**

    *   **Step 6:** The Restaurant venue profile should be created successfully, and a confirmation message should be displayed.
    *   **Step 7:** All the entered data should be displayed accurately and in the expected format on the venue profile page.
    *   **Step 8:** The system should display an appropriate error message indicating that the file type is invalid or the file size exceeds the limit. The venue profile should not be saved.
    *   **Step 9:** The system should display an appropriate error message indicating that the "Commission" field requires a numeric value. The venue profile should not be saved.
    *   **Step 10:** The system should display an appropriate error message indicating that the "Min/Max Party Size" fields requires a numeric value and it should be positive. The venue profile should not be saved. It should also throw an error if max < min.
    *   **Step 11:** The system should display an appropriate error message indicating the invalid data input for price range.
    *   **Step 12:** If valid data, the venue profile should be created successfully and a confirmation message should be displayed.

*   **Priority:** High (Data integrity is crucial)
