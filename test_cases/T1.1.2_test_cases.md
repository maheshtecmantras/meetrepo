**Test Case 1: Verification of Total Signed Venues Count**

*   **Title:** Verify Total Signed Venues Count Accuracy

*   **Description:** This test case verifies that the total number of signed venues displayed on the Venues Metrics dashboard accurately reflects the actual count of venues with signed contracts within the system.

*   **Steps:**

    1.  **Pre-condition:** Ensure you have access to the Venues Metrics dashboard and the venue management database.
    2.  **Access Venue Management Database:** Query the venue management database to retrieve the total count of venues with a "Signed" contract status.  Record this count as the "Expected Total Signed Venues Count".  Include relevant criteria in the SQL query, such as 'contract_status = "Signed"' and 'contract_start_date <= CURRENT_TIMESTAMP' and 'contract_end_date >= CURRENT_TIMESTAMP' to ensure you are only counting active signed venues.
    3.  **Navigate to Venues Metrics Dashboard:** Log in to the application and navigate to the "Venues Metrics" dashboard.
    4.  **Locate Total Signed Venues Metric:** Find the metric labeled "Total Signed Venues" on the dashboard.
    5.  **Compare Displayed Count with Expected Count:** Compare the "Total Signed Venues" count displayed on the dashboard with the "Expected Total Signed Venues Count" obtained from the database query.
    6. **Add a new Venue:** Add a new venue to the database with status 'Signed'
    7. **Refresh the dashboard**
    8. **Repeat steps 5 and 6**
    9. **Delete the new venue:** Remove the venue added in step 6.
    10. **Refresh the dashboard**
    11. **Repeat steps 5 and 6**

*   **Expected Result:**

    *   The "Total Signed Venues" count displayed on the Venues Metrics dashboard must exactly match the "Expected Total Signed Venues Count" retrieved from the database in steps 5, 8 and 11. Any discrepancy indicates a failure.

*   **Priority:** High

**Test Case 2: Verification of New Venues Onboarded Metric with Date Filtering**

*   **Title:** Verify New Venues Onboarded Count with Date Filtering

*   **Description:** This test case verifies that the "New Venues Onboarded" metric accurately reflects the number of venues onboarded (defined as having their contract signed) within a specified date range, using the date filtering functionality on the dashboard.

*   **Steps:**

    1.  **Pre-condition:** Ensure access to the Venues Metrics dashboard and the venue management database. There should be a sufficient number of venues onboarded within varying date ranges for accurate testing.
    2.  **Select Date Range:** On the Venues Metrics dashboard, locate and use the date range filter. Select a specific date range (e.g., last week, last month, or a custom range).
    3.  **Access Venue Management Database:** Query the venue management database to retrieve the count of venues that had their contract signed (contract status set to "Signed") within the date range selected in step 2. Record this count as the "Expected New Venues Onboarded Count." Include relevant criteria in the SQL query, such as 'contract_status = "Signed"' and 'contract_contract_start_date BETWEEN "selected start date" AND "selected end date"'.
    4.  **Locate New Venues Onboarded Metric:** Find the metric labeled "New Venues Onboarded" on the dashboard.
    5.  **Compare Displayed Count with Expected Count:** Compare the "New Venues Onboarded" count displayed on the dashboard with the "Expected New Venues Onboarded Count" obtained from the database query.
    6.  **Repeat Steps 2-5 with different date ranges,** including:
        *   A date range with no new venues onboarded.
        *   A date range that spans multiple months.
        *   A date range that starts in the past and ends in the future (using current date as the 'future' point).
        *   A custom date range selecting a very small number of days (e.g., 2-3 days).
    7. **Verify the "Today" functionality works correctly**:  Select the Today filter and confirm that only venues onboarded today are displayed. Compare with the database.

*   **Expected Result:**

    *   For each date range selected, the "New Venues Onboarded" count displayed on the Venues Metrics dashboard must exactly match the "Expected New Venues Onboarded Count" retrieved from the database query for that specific date range.  Any discrepancy indicates a failure. Especially important is verifying "0" is displayed correctly when no venues were onboarded within the selected date range.

*   **Priority:** High
