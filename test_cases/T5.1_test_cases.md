# Test Cases for T5.1 - User Profile Management

Okay, here are two detailed test cases based on the provided task "User Profile Management: Create/Update User," designed from the perspective of a senior QA engineer.

**Test Case 1: Successful User Creation with Mandatory Fields Only**

*   **Title:** Create New User - Successful Creation with Mandatory Fields

*   **Description:** This test case verifies the successful creation of a new user account when only the mandatory fields are populated. This ensures that the core user creation functionality is working as expected.

*   **Steps:**

    1.  Navigate to the User Management section of the application.
    2.  Click on the "Create New User" button.
    3.  Locate the mandatory fields required for user creation (e.g., First Name, Last Name, Email Address, Password, Role).  *Note:  The specific mandatory fields should be clearly defined in the system requirements documentation. If not available, clarify with the business analyst.*
    4.  Enter valid and unique data into all mandatory fields.  Consider using a standard email naming convention like "test+<date><timestamp>@example.com" to ensure uniqueness.
    5.  Leave all optional fields blank.
    6.  Click the "Save" or "Create" button.
    7.  Observe the system response.

*   **Expected Result:**

    1.  The system should successfully create the new user account.
    2.  A success message should be displayed to the user (e.g., "User successfully created"). The message should be clear and informative.
    3.  The new user account should be visible in the user list/table with the correct information populated.
    4.  The system should not display any error messages or warnings.
    5.  The user should be able to log in using the credentials created in this test.

*   **Priority:** High

**Test Case 2: User Update - Successful Update of All Fields**

*   **Title:** Update Existing User - Successful Update of All Fields

*   **Description:** This test case verifies the successful update of an existing user's profile, including both mandatory and optional fields. This ensures that the user profile update functionality is working correctly and that all data is saved as expected.

*   **Steps:**

    1.  Navigate to the User Management section of the application.
    2.  Locate an existing user account from the user list. *Note: Choose a user who is not an administrator or a user with specific permissions that might complicate the test.*
    3.  Select the user and click on the "Edit" or "Update" button associated with that user.
    4.  Modify all fields in the user profile, including:
        *   Mandatory fields (e.g., First Name, Last Name, Email Address)
        *   Optional fields (e.g., Phone Number, Address, Department, Profile Picture)  *Note: Consider edge cases and boundary conditions for optional fields, such as maximum character length or valid date ranges.*
        *   If available, change the user's role or permissions (but ensure this doesn't lock you out of the system!).
    5.  Click the "Save" or "Update" button.
    6.  Observe the system response.

*   **Expected Result:**

    1.  The system should successfully update the user profile.
    2.  A success message should be displayed to the user (e.g., "User profile successfully updated").
    3.  The user profile details in the user list/table should reflect all the changes made.
    4.  The system should not display any error messages or warnings.
    5.  If the user's email address or password was changed, the user should be able to log in with the new credentials.
    6.  If the user's role or permissions were changed, the user should have the updated access rights.

*   **Priority:** High
