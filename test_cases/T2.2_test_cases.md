# Test Cases for T2.2 - Venue Profiles Clubbing

Okay, here are two detailed test cases for the "Venue Profiles Clubbing" task, simulating the creation and update scenarios.

**Test Case 1: Create New Venue Profile for Clubbing**

*   **Title:** Verify Successful Creation of New Clubbing Venue Profile with Valid Data

*   **Description:** This test case validates that a new venue profile, specifically for a clubbing venue, can be successfully created within the system using valid data for all required and optional fields.  It checks if the profile is saved correctly and is accessible.

*   **Steps:**

    1.  **Precondition:** Login to the system with a user account that has permissions to create venue profiles.
    2.  **Navigation:** Navigate to the "Venue Management" or "Venue Profiles" section of the application.
    3.  **Initiate Creation:** Click on the "Create New Venue" or similar button/link.
    4.  **Select Venue Type:** Choose "Clubbing" or a similar option from the "Venue Type" dropdown or selection.
    5.  **Enter Required Fields:**
        *   Enter a valid and unique "Venue Name" (e.g., "Pulse Nightclub").
        *   Enter a valid "Address" (e.g., "123 Main Street").
        *   Enter a valid "City" (e.g., "Anytown").
        *   Enter a valid "State/Province" (e.g., "CA").
        *   Enter a valid "Zip/Postal Code" (e.g., "90210").
        *   Enter a valid "Country" (e.g., "USA").
        *   Enter a valid "Contact Phone Number" (e.g., "555-123-4567").
    6.  **Enter Optional Fields:**
        *   Enter a "Website URL" (e.g., "www.pulsenightclub.com").
        *   Enter a "Description" (e.g., "Pulse Nightclub is the hottest club in town!").
        *   Select relevant "Music Genres" (e.g., "Electronic", "Hip-Hop", "Pop").
        *   Upload a "Venue Image" (select a valid image file).
        *   Enter "Opening Hours" (e.g., "Friday & Saturday 10:00 PM - 3:00 AM").
        *   Enter "Age Restriction" (e.g., "21+").
    7.  **Save Profile:** Click the "Save" or "Create" button.

*   **Expected Result:**

    1.  A success message (e.g., "Venue profile created successfully") is displayed.
    2.  The user is redirected to the newly created venue profile page or back to the venue list with the new venue appearing in the list.
    3.  All entered data, including the Venue Name, Address, Contact Information, Description, Music Genres, Image, Opening Hours, and Age Restriction, are correctly displayed on the venue profile page.
    4.  The newly created venue profile is searchable within the system by name, address, or other relevant criteria.
    5.  The venue image is displayed correctly.
    6.  Data is stored in the database as expected with the correct field name and the data is not truncated, malformed, or corrupted.

*   **Priority:** High

**Test Case 2: Update Existing Clubbing Venue Profile**

*   **Title:** Verify Successful Update of Existing Clubbing Venue Profile with Valid Data

*   **Description:** This test case validates that an existing clubbing venue profile can be successfully updated with valid data for all editable fields.  It checks if the changes are saved correctly and reflected in the profile.

*   **Steps:**

    1.  **Precondition:** Login to the system with a user account that has permissions to edit venue profiles. Ensure a Clubbing Venue Profile exists (e.g., the one created in Test Case 1 or a pre-existing profile).
    2.  **Navigation:** Navigate to the "Venue Management" or "Venue Profiles" section of the application.
    3.  **Search for Venue:** Search for the target clubbing venue profile (e.g., using the "Venue Name" or "Address").
    4.  **Select Venue:** Select the target venue profile from the search results.
    5.  **Initiate Update:** Click on the "Edit" or "Update" button/link associated with the venue profile.
    6.  **Modify Fields:**
        *   Change the "Venue Name" (e.g., from "Pulse Nightclub" to "Pulse 2.0").
        *   Update the "Address" (e.g., change the street number).
        *   Modify the "Description" (e.g., add information about a new DJ).
        *   Add or remove a "Music Genre".
        *   Replace the existing "Venue Image" with a new image.
        *   Update the "Opening Hours".
        *   Update the "Age Restriction"
    7.  **Save Changes:** Click the "Save" or "Update" button.

*   **Expected Result:**

    1.  A success message (e.g., "Venue profile updated successfully") is displayed.
    2.  The user is redirected to the updated venue profile page.
    3.  All modified data, including the Venue Name, Address, Contact Information, Description, Music Genres, Image, Opening Hours, and Age Restriction, are correctly displayed on the venue profile page reflecting the changes made in Step 6.
    4.  The updated venue profile is searchable within the system using the new Venue Name or Address.
    5.  The updated image is displayed correctly.
    6.  The database reflects the updated information.

*   **Priority:** High
