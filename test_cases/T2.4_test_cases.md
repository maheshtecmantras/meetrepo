# Test Cases for T2.4 - Create/Update Events

Okay, here are two detailed test cases based on the provided "Create/Update Events" task. These test cases focus on different aspects of the functionality.

**Test Case 1: Successful Event Creation with Full Details**

*   **Title:** Verify Successful Event Creation with All Optional Fields Populated

*   **Description:** This test case verifies that a user can successfully create a new event, populating all mandatory and optional fields, and that the event is saved correctly within the system. It covers the full range of fields to ensure data integrity.

*   **Steps:**

    1.  Navigate to the Event Management section of the application.
    2.  Click on the "Create Event" or "Add Event" button.
    3.  Enter a valid and unique event name in the "Event Name" field (e.g., "Summer Music Festival 2024").
    4.  Select a future date and time using the date/time picker for the "Date & Time" field (e.g., August 15, 2024, 7:00 PM).
    5.  Enter a valid venue name in the "Venue" field (e.g., "Central Park Amphitheater").
    6.  Enter a detailed event description in the "Event Description" field. (e.g., "A three-day music festival featuring top artists from around the world...")
    7.  Select "Guestlist Info Available" and populate required fields like Contact Details, RSVP Date.
    8.  Select "Table Bookings Available" and enter table booking details like Table price, Number of tables.
    9.  Enter relevant discount details in the "Discount Details" field, including discount percentage and validity dates (e.g., "Early Bird Discount: 10% off until July 1st").
    10. Upload a relevant creative (image/video) to the "Creatives" field.
    11. Enter a compelling description/caption for the creative in the "Description/Caption" field (e.g., "Join us for an unforgettable summer experience!").
    12. Click the "Save" or "Create Event" button.

*   **Expected Result:**

    1.  The system should successfully create the event without any error messages.
    2.  A success message should be displayed to the user confirming event creation (e.g., "Event created successfully!").
    3.  The newly created event should be visible in the event list or event calendar, displaying all the entered information accurately.
    4.  The uploaded creative should be correctly associated with the event and displayed in the appropriate sections of the application.
    5.  The event details page should accurately reflect all entered data including name, time, venue, description, guestlist settings, table booking status and discounts.

*   **Priority:** High (P1) - This is a core function of the system and must work reliably.

**Test Case 2: Event Creation with Mandatory Fields Only and Validation**

*   **Title:** Verify Event Creation with Only Mandatory Fields and Required Field Validation

*   **Description:** This test case verifies that the system correctly validates the mandatory fields during event creation and prevents the creation of an event if these fields are not filled in. It also checks if a basic event can be created successfully when only the required fields are provided.

*   **Steps:**

    1.  Navigate to the Event Management section of the application.
    2.  Click on the "Create Event" or "Add Event" button.
    3.  Leave the mandatory fields "Event Name," "Date & Time," and "Venue" blank.  (Determine mandatory fields from requirements, if not clear, assume these are mandatory)
    4.  Attempt to click the "Save" or "Create Event" button.
    5.  Now, populate the mandatory fields with valid data:
        *   "Event Name": "Simple Gathering"
        *   "Date & Time": A future date and time
        *   "Venue": "Local Community Hall"
    6.  Leave all other fields (Event Description, Guestlist Info, Table Bookings, Discount Details, Creatives, Description/Caption) blank.
    7.  Click the "Save" or "Create Event" button.

*   **Expected Result:**

    1.  **Step 4:**  The system should display error messages indicating that the "Event Name," "Date & Time," and "Venue" fields are mandatory and must be filled in.  The event creation should be blocked.
    2.  **Step 7:** The system should successfully create the event with the provided mandatory information.
    3.  A success message should be displayed to the user.
    4.  The newly created event should be visible in the event list or event calendar, displaying the entered information.
    5.  All optional fields should be displayed as blank or with default values as defined in the requirements.

*   **Priority:** High (P1) - Mandatory field validation is crucial for data integrity and preventing incomplete event creation.
