# Test Cases for T5.1.3 - Referral Information

Here are the two test cases, focusing on different aspects of the feature:

**Test Case 1: Verifying Referral Information Display on User Profile**

*   **Title:** Verify Display of Referrer and Referral Count on User Profile
*   **Description:** This test case verifies that the referrer's name and the number of referrals made by a user are correctly displayed on the user's profile page after a referral relationship has been established.
*   **Steps:**

    1.  **Precondition:**
        *   User A exists.
        *   User B exists.
        *   User B has referred User A (using the referral mechanism – e.g., referral link, referral code).
    2.  Log in to the application as an administrator or a user with permission to view User A's profile.
    3.  Navigate to User A's profile page.
    4.  Locate the "Referral Information" section (or equivalent section where referral details are displayed).
    5.  Observe the displayed information.
*   **Expected Result:**

    *   The "Referral Information" section exists on User A's profile page.
    *   The name of User B (the referrer) is displayed correctly.
    *   The number of referrals made by User B is incremented by at least one and displays correctly on User B's profile page.
*   **Priority:** High - Correctly displaying referral information is essential for tracking and potentially rewarding referrals.

**Test Case 2: Verify Referral Count Update Upon Successful Referral**

*   **Title:** Verify Referral Count Increment After Successful Referral
*   **Description:** This test case verifies that the "number of people they have referred" is correctly updated for the referrer after a new user successfully registers using their referral mechanism.
*   **Steps:**

    1.  **Precondition:**
        *   User C exists.
        *   The referral system is active and functional (e.g., referral links, referral codes are working).
        *   User C has 0 referrals.
    2.  Log in to the application as User C.
    3.  Locate the referral link or code associated with User C.
    4.  Log out from User C.
    5.  Create a new user account (User D) using User C's referral link or code.
    6.  Verify that User D's registration is successful.
    7.  Log in to the application as User C.
    8.  Navigate to User C's profile page or referral dashboard.
    9.  Observe the number of referrals made by User C.
*   **Expected Result:**

    *   User D can successfully sign up using User C's referral code/link.
    *   The number of referrals made by User C is now 1.
    *   No other user's referral counts are affected by the successful referral of User D.
*   **Priority:** High - Accurately tracking referral counts is crucial for incentivizing referrals and providing accurate rewards.

These test cases are designed to cover the main functionalities related to displaying referral information and updating referral counts.  Depending on the specific implementation of the referral feature, additional test cases might be needed to cover edge cases, error handling, and security aspects.
